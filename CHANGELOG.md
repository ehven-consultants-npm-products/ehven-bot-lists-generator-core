# Changelog

## 1.0.0

- Explicit, copied and frozen public inventories with protected-root checks.
- Robots/discovery text, RSS entry selection, exact sitemap filtering and humans/security metadata.
- Strict path, control-character, credential-free HTTPS and calendar/timezone validation.
- Typed ESM root and publication, metadata and integrations entry points.
- Zero runtime dependencies, no install hooks and caller-owned hosting/configuration.

For stable 1.x, breaking public-contract changes require a major version;
compatible additions use a minor version, and compatible fixes use a patch version.
